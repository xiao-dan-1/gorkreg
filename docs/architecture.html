Grok 纯协议注册

产号拿 SSO → 入账拿 token → 探活保活 → 按需出包上传。 mint / refresh / remint / probe → auth.json only。 协议 grokreg/oauth（无 grokreg 协议 cpa）。 花名册 sso_roster.txt = email----password----sso。 证据 output/accounts/。导出目录 cpa_export/。 主路径 分步可独立；一条龙 暂不开发。

分层契约

  • 协议只 import grokreg.oauth
  • mint / refresh / probe → auth.json only
  • export / upload 旁路；mint 默认 packs=[]
  • refresh 禁读 cpa_export（export only）
  • 用例可独立跳步

日常分步

  • batch 注册（proxy-retries）
  • --mint-missing · newest-first · -j1
  • --probe-quota · --sso-audit
  • --recover-sso-roster
  • --export cpa_files → --cpa-upload

三落点

  • auth.json · RT/AT · 无 SSO
  • sso_roster · email----password----sso
  • output/accounts/ · 证据（滚动）
  • 双写：record_register_success
  • output 根不散落 account_*.json

失败 / 韧性

  • register：proxy 重试 1 次
  • mint rate_limit：串行重试 · 不写 pack
  • invalid_grant → remint（需 sso_roster）
  • 缺 pack：先 export 再 upload
  • 禁止一条龙拖全链

CPA 导出词 ≠ 协议

  • 目录：cpa_export/
  • 后端：cpa_files
  • 命令：ops/cpa_upload · env CPA_*
  • 健康：cpa_health
  • 实现：backends/export/xai_pack

模块 / 未还
