## 分层（必须）

```text
mint / remint / refresh  →  auth.json only
export cpa_files|sub2api →  本地 pack
cpa-upload / sub2api-upload → 远端
```

| 层 | 真源 | 禁止 |
|----|------|------|
| 凭证生命周期 | `auth.json` | 读坏 `cpa_export` 挡 refresh |
| export | 从 ledger 出包 | 当作 mint 默认副作用 |
| upload | pack / API | 回写 RT 逻辑 |

## 契约（防回归）

- 协议只从 `grokreg.oauth` 导入；**不存在** `grokreg.cpa` 协议包
- `cpa_upload` / `xai_pack` / `cpa_export` 仅为 export 产品名，不是 OAuth 模块

- `--refresh` / `--probe-quota` 不得以 cpa_export 为前置条件
- remint/mint 默认 `packs=[]`
- 要 CLIProxy 文件：显式 `--export cpa`（≡ `cpa_files` / `cliproxy`）
- 要 Cockpit Tools 导入：显式 `--export cockpit`（≡ `cp`）；目录 `cockpit_export/`（非 mint 默认）
- `refresh_entry` 必须更新 `expires_at`（与 JWT exp 一致）；CLI 不得传 `cpa_dir`
- 写 sso_roster：`from grokreg.ops.ledger_ops import append_sso_roster`（禁止 scripts 依赖 `_append_*`）

## 架构图约定（docs/architecture.html）

- 用例框可独立，禁止画成强制 1→2→3→4 流水线
- 一条龙最多脚注一行（曾临时用 / 暂不开发），不占 ENTRY 主位
- EXTERNAL 标注「← 阶段」；失败域单独一行
- SSO：auth.json 写模型 · sso_roster remint 输入 · output 证据
- CLIProxy 导出词：目录 / 命令 / 远端产品 ≠ 协议模块
